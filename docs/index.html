Engineering GitHub

Ownership

What this proves

Three layers one person owns — not a thin UI over someone else’s engine.

  • DSP / core

    Generative engines (Euclidean, algorithmic, stochastic/chaos), scale quantization, swing, gate, and ratchet paths that feed MIDI scheduling.

  • Format wrapper

    macOS AU, VST3, and Standalone build-verified. AUv3 is a configured CMake target with iOS docs — not store-ready.

  • Evidence discipline

    Status, build verification, design specs, smoke checklist, and session notes live in-repo. Claims point at those files — not at enthusiasm.

Practice

Agentic engineering practice

AI-fluent workflow with a human owner as the gate — written decisions before code, re-verification from disk after.

  1. Written decisions Capture intent and constraints in status, design, or session notes before changing the realtime path.
  2. Interface plans Sketch parameter surfaces and UI contracts (LookAndFeel / bitmap specs) so engines and editor stay aligned.
  3. Implementation Ship C++/JUCE changes across core, processor, and formats — one coherent system, not a demo script.
  4. Independent re-verification Re-read artifacts from disk: builds, STATUS, and source — not chat memory — before calling work done.

The human remains accountable for what ships and what stays deferred. No vendor branding; no “AI built this” framing.

Honesty

Boundary — shipped vs deferred

Grounded in STATUS.md (v0.8.0) and BUILD_VERIFICATION.md. Development status — not finished product polish.

Shipped / verified

  • v0.8.0 per STATUS (~37 parameters incl. expression + LFO; MIDI channel; stochastic UI).
  • macOS AU / VST3 / Standalone (historical local); CI: macOS + iOS + Windows + Linux via .github/workflows/ci.yml + pluginval (VST3).
  • 10 generators in the editor (Euclidean, experimental Polyrhythm, Markov, L-System, Cellular, Probabilistic, Brownian, Perlin, Drunk Walk, Lorenz).
  • Factory presets live (11 including Polyrhythm Layers).
  • MIDI expression — note-on AT / PB / CC (static PB — not MPE). ADVANCED LFO → velocity (and density) — not a full modulation matrix.
  • Realtime hot-path hardening — Euclidean / ratchet / algorithmic / EventScheduler steady-state alloc-free. Residual: trained Markov map-key vector.
  • Evidence: Catch2 / ctest in CI (20+) + format builds. Manual smoke: SMOKE_CHECKLIST.md.

Deferred / not claimed

  • App Store / finished product polish; listening clips for this site.
  • AUv3 as store-ready — configured target + iOS docs only.
  • Full modulation matrix UI; continuous CC/PB / MPE; Polyrhythm step-grid polish.
  • Dedicated touch / accessibility redesign; test coverage percentages.
